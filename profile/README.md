# 👋 OCPSS — Organização Colaborativa de Projetos de Sistemas de Software

A **OCPSS** centraliza, organiza e compartilha os projetos desenvolvidos na disciplina de **Projetos de Sistemas de Software (PSS)** da **UFES**, promovendo a colaboração, o versionamento adequado e as boas práticas de desenvolvimento em equipe.

---

## 🎯 Objetivos

- Centralizar os projetos da disciplina em um único ambiente
- Estimular o trabalho colaborativo com Git e GitHub
- Aplicar boas práticas de versionamento e organização de código
- Facilitar o acompanhamento e a avaliação dos projetos
- Criar um portfólio acadêmico dos trabalhos desenvolvidos

## 🤝 Como colaborar

- Todos os integrantes devem contribuir com commits
- Mensagens de commit claras e objetivas
- Uma branch por funcionalidade e **Pull Requests** sempre que possível
- Código organizado, com nomenclatura padronizada
- **README obrigatório** em cada projeto

📖 O passo a passo completo e o modelo de README estão no repositório **[OCPSS](https://github.com/OCPSS/OCPSS#como-contribuir)**.
