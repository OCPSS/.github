# .github — OCPSS

Repositório especial da organização **[OCPSS](https://github.com/OCPSS)** (Organização Colaborativa de Projetos de Sistemas de Software).

O GitHub usa este repositório para configurações e conteúdos compartilhados por toda a organização.

---

## 📁 Estrutura

| Caminho | Função |
|---|---|
| [`profile/README.md`](profile/README.md) | Página de apresentação exibida em [github.com/OCPSS](https://github.com/OCPSS) |

---

## ✏️ Como editar o perfil da organização

1. Edite o arquivo [`profile/README.md`](profile/README.md).
2. Faça commit e push para a `main`.
3. A página [github.com/OCPSS](https://github.com/OCPSS) é atualizada automaticamente.
